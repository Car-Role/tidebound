## Needs from others

- **WP1/WP14, `client/main.js`**: the frame loop starts only after `await` on the title, so a panel with `auto: false`
  is never drawn (black screen). **Worked around in `title.js`**: while it is open and the panel manager has not
  drawn it in the last 250 ms, the title runs its own rAF loop on `#game` and captures mouse and keys in the capture
  phase, so the game's Input never sees keys typed into the name field. It steps aside automatically if the manager
  draws it. No patch is required. The clean fix for WP14, if wanted, is to start `requestAnimationFrame(frame)` before
  the title `await` and have `frame()` call `ui.update(dt)`, `renderer.frame(dt, t, time, null, null)` and
  `input.endFrame()` while not yet connected (it already does this in the `else` branch).
- **WP6a**: skill points from WP11 sources come from the extra service `extraSkillPoints(player)`: 1 per completed
  Archive wing (world, survives Rebirth) + 1 for this run's Drowned Moon kill. Bus `skillpoint.granted {player|null, n, source}`
  is also emitted. Please add it to the player's point total.
- **WP6a / WP5 / WP8**: Moon Chart effects need `game.call('moonRank', player, perkId)`: `moon_keep` (keep_card),
  `moon_draft` (draft_offer_tens), `moon_trinkets` (boss_trinkets), `moon_scuttler` (scuttler_tier). Stat mods,
  world mods and flags of perks are already applied through stat sources named `moon`.
- **WP6b / WP9 / WP10**: castaway line rewards that are effects: `game.call('lineEffects', player)` returns
  `[{ id, ...params, npc }]`: `temper_glint_discount` (Brannick, WP6b), `rod_rare_fish` (Ysolde, WP9).
  Morrow's `trench_no_key` is a flag (`game.stats.hasFlag`) for every player once anyone finishes the line (WP10).
- **WP7**: line completion sets `world.flags['line:<npcId>'] = true` and emits `questline.completed {npc, biome}`;
  use either for Beacon attunement. Main quests set `quest:<id>`. WP11 spawns castaway NPCs itself on owned
  `castaway` plots (biome order = plot index order) and does not need WP7 to place them; it reuses an existing NPC

- **WP7 `spendGlint`**: spend caps are enforced by coop.js wrapping the registered `spendGlint` (re-wraps itself if

## Contracts others can use

- `self.ui = { panel, ...args, t }` opens that panel with those args (router in hud/toasts.js, ignores requests older
  than 3 s); `{ close: '<panelId>' }` closes one. Any package may use it.
- self keys added: `quests`, `deeds`, `moon`, `prefs`. World keys: `mainQuest`, `archive`, `tidegate` (includes
  `finale` and `cutscene`), `rebirth`, `coop`, `party`, `telemetry`.
- `chat` messages may carry `ping: {x, y, kind, realm, id}` and `sys: 1` for system lines.
- Action payload extension: `tidegate.deliver {stage: 6}` after stage 5 = descend to the Drowned Moon (no new action name).
- Extra services: `counterMax`, `lineEffects`, `questDone`, `questAccept`, `extraSkillPoints`, `moonRank`, `spendAllowed`.
- Bus: `finale.changed {stage}` (internal), `skillpoint.granted`.

## Deviations and interpretations

- "New world" on the title: one server runs one world, so the title offers Continue / New castaway (fresh character
  token) / Join by address / Host a new world (shows the `npm start -- --world NAME` command) / Settings. World info on
  the title is the last-seen `world.coop` cached in localStorage (there is no pre-join info message).
- Main quests auto-complete; item and XP rewards go to every connected player, XP is banked for offline bound players.
  q23's 2 Moon Shards and Nix's +3 are banked into the Turning formula. Glint cap uses `landCostNext()` at completion.
- Moon Shards level term = floor(average bound-player level / 100), read literally from DESIGN 18.2.
- `moon_tokens` grants `rank` Tide Tokens at each Turning (the "per 5 levels" wording is ambiguous).
- Rebirth deletes `profile.sys.{cards, skills, gear, consumables, abilities, dungeons, quests}` for offline profiles;
  connected players' other-system state must be reset by those systems on the `rebirth` bus event. World flags kept:
  `wing:*`, `quest:s_*` (recipe unlocks), `moon:beaten`; per-run telemetry moves into rebirth history.
- Side quest "raise N plots" counts any plot raised while active (raising is a crew action).
- The tutorial card is drawn by the toasts HUD (not opened as a panel) so Esc never closes it; progress is a bitmask
  in prefs `tut`, Shift-click hides all, Esc > Tutorial tips brings them back.
- Chat: 160 chars, 5 lines per 8 s, 0.35 s minimum gap; pings 0.75 s cooldown.
